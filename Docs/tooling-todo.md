# Next Tooling Improvements

1. **Integration Surface Atlas** — Index native Lancer extension points: Flows, Flow steps, hooks, chat actions, `game.lancer.*`, Actor/Item entry points, damage and targeting boundaries.

2. **Runtime Signal Map** — Map event/runtime flow rather than imports: click → Flow → hook → chat → damage → document mutation.

3. **Clause-Aware Patch Corridor** — Break behavioral goals into clauses and require an architectural owner/path for each clause before declaring the corridor complete.

4. **Corridor Context Pack** — Return only the exact relevant file slices, symbols, imports, callers, exemplars, and ownership notes instead of making us reopen whole files.

5. **Native Contract Catalog** — Persist already-proven native integration facts with source/hash/version evidence so we do not repeatedly rediscover authoritative APIs and boundaries.

6. **Automatic Patch Staging** — Use the dependency graph to propose safe implementation phases and generate staged FilePatcher specs for large cross-cutting changes.

7. **More Pattern-Aware DSL Forms** — Add a few high-value exemplar-driven shorthands such as `feature-registration`, `runtime-binding`, `feature-api-member`, `hook-handler`, `flow-step`, and `actor-flag`.

8. **Runtime Contract Probes** — Generate targeted Foundry runtime instrumentation for the specific patch so live testing produces structured proof of hooks, state changes, Flow behavior, and cleanup.
