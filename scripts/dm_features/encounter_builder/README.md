# Frame Conn DM Features — Encounter Builder

This directory is reserved for a GM-facing **Encounter Builder** for tactical and mission encounters.

## Future responsibility

The Encounter Builder should help a GM assemble an encounter from NPCs, templates/features, terrain/scenario assumptions, SITREP choice, deployment groups, reinforcements, reserves, objectives, and encounter difficulty/structure.

It should integrate naturally with `dm_features/sitreps/` and the Mission Toolkit's **Boots on the Ground** stage so an encounter authored before play becomes the same encounter state operated during play.

Where Foundry can represent encounter participants, scenes, tokens, folders, or combatants natively, use those documents rather than maintaining disconnected copies.

## Current state

Scaffold only. Nothing in this directory is registered or executed yet.
