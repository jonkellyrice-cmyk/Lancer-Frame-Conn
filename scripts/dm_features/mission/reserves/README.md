# Mission Stage 3 — Reserves

Future responsibility: organize strategic support and mission-duration advantages available to the group.

Planned support includes custom reserves plus rules-backed resources such as access, information, supplies, gear, allies, tactical advantages, temporary mech benefits, support actions, and other expendable mission assets.

This stage should eventually integrate with Narrative Play/Downtime so reserves earned between missions can be promoted directly into the next mission plan, then tracked as available, consumed, or expired during play.
