# Mission Stage 5 — End of Mission / Debrief

Future responsibility: close the mission and carry its consequences forward.

Planned support includes objective outcomes, partial successes/failures, unresolved complications, rewards, reserve/reputation consequences, damage/repair and downtime handoff, NPC/faction/world-state changes, debrief notes, and hooks for future missions.

The debrief should transform live mission state into durable campaign state instead of forcing the GM to reconstruct everything manually afterward.
