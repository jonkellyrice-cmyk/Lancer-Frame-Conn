# Mission Stage 1 — Briefing

Future responsibility: help the GM author and present the opening mission brief.

Planned data includes the **situation**, **goal/objectives**, **stakes**, factions, relevant people and locations, known threats, intelligence, uncertainties, and a clean separation between GM-only notes and material that can be revealed to players.

The briefing should become reusable mission state rather than disposable prose: objectives and known facts created here should flow into later preparation and live mission views.
