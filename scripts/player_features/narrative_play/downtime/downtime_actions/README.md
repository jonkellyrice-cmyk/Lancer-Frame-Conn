# Narrative Play — Downtime Actions

Future responsibility: define reusable structured downtime actions with consistent player-input, roll, outcome, and persistence contracts.

Initial core action set includes:

- Power at a Cost;
- Buy Some Time;
- Gather Information;
- Get a Damn Drink;
- Get Creative;
- Get Focused;
- Get Organized;
- Get Connected;
- Scrounge and Barter.

Each action should eventually be able to define required narrative input, relevant triggers, native roll execution, 9-/10–19/20+ outcome bands, post-roll choices, complications, persistent project/contact/organization changes, and Reserves generated.

Custom GM-created downtime actions should use the same definition model rather than requiring bespoke UI code.
