# Narrative Play — Skill Checks

Future responsibility: coordinate the player-facing workflow for narrative skill checks.

Planned support includes:

- player names the goal before rolling;
- GM establishes consequences of failure where appropriate;
- player chooses the relevant trigger/background;
- ordinary, Difficult, Risky, and Heroic roll modes;
- Accuracy/Difficulty and other native modifiers;
- result interpretation for 9 or less, 10+, and Heroic 20+ outcomes;
- Teamwork assistance;
- pushing failed checks and enforcing the rule against simply repeating the same failed approach without changed circumstances;
- clear chat/UI presentation of the goal, stakes, roll mode, result, and consequences.

Use native Foundry Lancer pilot roll data/execution wherever possible rather than creating a separate Narrative Play dice engine.
