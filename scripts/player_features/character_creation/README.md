# Frame Conn Player Features — Character Creation

This directory is reserved for a player-facing **Character Creation** workflow.

## Future responsibility

Character Creation should guide a player through building a new Lancer pilot using native Foundry Lancer Actor/Item data wherever possible. Planned concerns include identity/background, triggers, talents, licenses, starting gear, pilot equipment, mech access, and any other creation-time choices required by the rules.

The feature should validate prerequisites and completion state, present choices in a guided sequence, and write through native Lancer document structures rather than creating a parallel Frame Conn character model.

## Relationship to other features

Character Creation establishes the initial pilot state that later feeds **Level Up**, **Mech Builder**, Narrative Play, Hardsuit, and Frame Conn tactical play.

## Current state

Scaffold only. Nothing in this directory is registered or executed yet.
