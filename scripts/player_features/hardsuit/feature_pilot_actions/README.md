# Hardsuit — Pilot Actions

Future responsibility: expose and execute the actions available to an unmounted pilot during mech combat.

Planned actions include:

- pilot-legal universal actions such as Boost, Hide, Search, Activate, Skill Check, Disengage, Prepare, Mount, and Overwatch where the rules allow them;
- **Fight** as the pilot's weapon-attack Full Action;
- **Jockey** as a dedicated contested/relationship-driven Full Action with continuing Distract, Shred, and Damage choices;
- **Reload** as a Quick Action for pilot weapons with Loading;
- pilot reactions and Overwatch using pilot equipment, position, Range, and Threat.

Where semantics genuinely match an existing universal action, reuse the existing execution infrastructure. Pilot-specific rules should not be forced through mech-only execution paths.
