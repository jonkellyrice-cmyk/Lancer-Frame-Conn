# Frame Conn Player Features — Mech Builder

This directory is reserved for a player-facing **Mech Builder**.

## Future responsibility

The Mech Builder should provide a focused workflow for constructing and editing a legal mech loadout from the pilot's licenses and unlocked content. Planned concerns include frame selection, HASE-derived stats where applicable, weapon mounts, weapons, mounted systems, core bonuses, frame traits/core systems, Limited resources, loadout capacity, and validation of build legality.

It should discover content from native Foundry Lancer Actor/Item data and the actor-owned feature registry. Native Lancer documents remain authoritative; Frame Conn should not maintain a duplicate mech build representation.

## Relationship to Phase 2

This feature depends heavily on the Phase 2 actor-owned content infrastructure. The same normalized discovery layer used by tactical execution should power build selection and validation.

## Current state

Scaffold only. Nothing in this directory is registered or executed yet.
