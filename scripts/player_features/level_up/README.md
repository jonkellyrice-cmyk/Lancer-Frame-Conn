# Frame Conn Player Features — Level Up

This directory is reserved for a guided player-facing **Level Up** workflow.

## Future responsibility

Level Up should take an existing pilot from one License Level to the next and guide the choices unlocked by advancement. Planned concerns include license ranks, talents, mech skills/HASE increases, core bonuses at the appropriate levels, newly available frames/systems/weapons, respec or replacement choices where the rules permit them, and validation that advancement is complete and legal.

The feature should operate on native Foundry Lancer Actor/Item state and reuse Character Creation and Mech Builder choice/validation services instead of implementing separate content catalogs.

## Design goal

A player should be able to open one advancement workflow, see exactly what choices remain at the new LL, make them in a safe order, and finish with a valid native pilot/mech state.

## Current state

Scaffold only. Nothing in this directory is registered or executed yet.
