# Narrative Play UI Components

Future focused presentation modules for the Narrative Play interface belong here.

Likely component families include:

- goal and stakes summary;
- trigger/background and roll-mode chooser;
- consequence preview/result presentation;
- Teamwork and push controls;
- Skill Challenge progress;
- narrative pilot harm/recovery state;
- Downtime action chooser and outcome prompts;
- projects, contacts, and organizations;
- Reserves inventory and mission handoff.

Components should remain presentation-focused and delegate behavior to `scripts/player_features/narrative_play/` and shared services.
