# Hardsuit UI Components

Future focused presentation modules for the pilot helmet-HUD belong here.

Likely component families include:

- compact pilot telemetry;
- shared activation/action-budget display;
- pilot weapon and gear selectors;
- Fight/Jockey/Reload controls;
- pilot-legal universal actions;
- status/condition indicators;
- occupancy/mount controls;
- compact targeting and nearby-threat information.

Components should remain presentation-focused and delegate actual behavior to `scripts/player_features/hardsuit/` and shared services.
